# 订单取消与修改政策

> 文档信息：版本 v1.0 ｜ 生效日期 2026-07-01 ｜ 编制单位：云舟商城客户服务部

## 1. 取消订单

### 1.1 未付款订单

- 未付款订单自创建起保留 **30 分钟**，超时未支付自动关闭。
- 保留期间用户可在订单详情页**自助取消**。
- 自动关闭或主动取消的未付款订单不产生任何费用。

### 1.2 已付款未发货订单

- 已付款且商品尚未发货的订单，用户可随时在订单详情页**自助取消**。
- 取消后按《退款政策》原路退款，1～3 个工作日到账。
- 订单已发货后不支持自助取消，按本章第 1.3 节处理。

### 1.3 发货后拦截

已发货订单不支持直接取消，用户可联系在线客服申请**拦截**：

1. 拦截成功的：包裹退回后按《退款政策》退款；拦截后若包裹仍被签收，按签收处理。
2. 拦截失败的：包裹按原地址派送，用户可选择拒收，退回后按拒收规则处理（详见《物流配送与异常处理》）。

拦截成功率受承运方网络影响，商城无法保证拦截必然成功。

### 1.4 取消订单的例外

- 预售商品已付款未发货同样支持自助取消（本章第 1.2 节），不因其为预售而受限。
- 定制商品已进入生产流程后不支持取消，具体以商品页标注的取消截止时间为准。

## 2. 修改订单

### 2.1 修改收货地址与联系方式

- **发货前**：用户可在订单详情页自助修改收货地址与联系电话，修改次数不限。
- **已发货**：不支持修改地址。地址有误的按《物流配送与异常处理》第 5.6 节处理（联系客服尝试拦截）。

### 2.2 修改商品信息

- 已付款未发货的订单不支持直接修改商品数量、规格或款式。
- 如需变更，可先取消订单重新下单；因价格变动产生的差额按正常交易执行，不享受价差补偿（价格保护规则见本章第 6 节）。

## 3. 拆单

1. 一个订单包含多件商品的，商城可按商品到货情况**拆分发货**，各包裹独立跟踪物流。
2. 拆单不影响订单中每件商品的退货、保修等售后权利（详见《退货与换货政策》与《商品质量与保修政策》）。
3. 拆单后部分包裹先签收的，无理由退货时限按各包裹**分别**从各自签收次日起算。
4. 拆单产生的额外运费由商城承担。

## 4. 缺货处理

1. 商品缺货无法在发货时效内发出的，商城在 **3 个工作日内**通知用户。
2. 用户可选择：
   - **等待补货**：商品到货后按原订单发出；等待期间可随时改为取消。
   - **取消该商品**：缺货部分立即取消并退款，其余商品正常发货。
3. 缺货商品连续 **7 天**无法补货且用户未明确选择的，按取消并退款处理。

## 5. 预售商品

1. 预售商品按商品页承诺的发货时间发出，不适用现货 48 小时发货时效。
2. 预售商品支持预付定金方式的，定金规则以商品页公示为准；尾款支付后发货流程与普通订单一致。
3. 预售商品未按承诺时间发货的，适用《延迟赔偿与售后补偿》的延迟发货赔偿（预售承诺时间作为发货时效基准）。
4. 预售商品的价格保护与其他订单一致（本章第 6 节）。

## 6. 价格保护

### 6.1 价保规则

商品签收后 **7 天内**，同一商品（同款同规格同配置）在云舟商城降价销售的，用户可申请价格保护：

1. 差价 = 购买时实付价 − 价保期内最低售价。
2. 差价以**无门槛优惠券**形式补偿，自发放之日起 **30 天内**有效。
3. 每单仅申请一次，按价保期内最低售价核定。

### 6.2 不适用价保的情形

1. 大促活动期间（618、双11）购买的商品。
2. 清仓、特价、秒杀商品。
3. 使用了不可叠加优惠的订单（以商品页标注为准）。
4. 价保期内用户已退货或部分退货的商品。

### 6.3 申请方式

订单详情页选择「申请价保」，系统自动核对同商品在价保期内的售价，24 小时内完成审核并发放补偿。

## 7. 重复下单与订单合并

1. 同一账号、同一收货地址、**30 分钟内**重复下单相同商品的，可在发货前联系客服申请**合并订单**。
2. 合并成功后：合并为一个订单发货，退还重复订单的运费，其余优惠按原订单各自保留。
3. 已发货的订单不支持合并。
4. 未申请合并的重复订单按正常订单独立发货，不强制合并。
